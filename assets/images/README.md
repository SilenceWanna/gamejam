# 图片目录

- `animation/act1`、`animation/act2`、`animation/act3`：各幕动画分镜图片。
- `animation/prologue`：序幕事务所双人镜头。
- `animation/he`、`animation/be`：两种结局动画图片，保留 END-HE / END-BE 原文件名。
- `background`：对话与场景背景；现有房间搜证背景也归入这里。
- `background/office`：事务所正式对话与推理背景；`reference` 中保存不进入游戏的空间母版。
- `characters`：角色立绘。
- `clues`：线索图片。
- `minigames/act1`、`minigames/act2`、`minigames/act3`：小游戏背景和阶段图片。
- `ui`：按钮、图标等界面素材。

素材保留原文件名。移动素材时同步更新代码及文档中的路径。

阿遥房间搜证背景采用调查模块命名：`MIA-C01-P1-INV-01_AyaoRoom.png`；第一、二幕共用该场景资源。
